## Architecture and protocol

No FlatBuffers schema change. The canonical OCCT core, versioned JSON session-control v1, existing typed command path, and Quest-as-client boundary remain in place; type 7 deletes supported leaf features through OCAF. Native Save/Open JSON and the `.icad` manifest gained the optional `referencePlanesJson` string; legacy files default to no references and clients omitting the Save field preserve loaded metadata.

JSON CreateHole/type 20 gains optional `insertBeforeId` through the existing Zod/native control-plane contract. Callers omitting it retain ordinary creation behavior. Insertion returns the new record plus the full recomputed feature/sketch list for projection refresh. No new command id or binary binding is required under the documented JSON-control/FlatBuffers-data protocol decision.

HolePattern canonical slots are `[diameterMm, depthMm, count]`; its `refExtra` keeps every authored center. Two-slot legacy labels adopt a derived full count without rewriting the file or creating an Undo step. Through-all depth remains hidden/uneditable. Count must be an integer between one and the authored-center count, including when supplied by a formula.
